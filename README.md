# StreamVibe - Entertainment & OTT Video Streaming Portal

**StreamVibe** is a modern, responsive OTT entertainment web application featuring on-demand movie streaming, episodic TV series, and interactive trailers.

## Key Features
- **Rich Media Catalog**: Browse curated libraries of movies and popular TV series (`movies.html`, `tvshows.html`).
- **Dedicated Watch Experience**: Watch pages with synopsis, cast information, genre tags, and embedded streaming players.
- **Trailer Previews**: Fast modal trailer viewing for upcoming releases and blockbuster titles.
- **Dark Mode OTT Aesthetic**: Sleek, immersive cinematic dark theme designed with modern CSS Flexbox and Grid.
- **Fully Responsive**: Flawless browsing across 4K displays, laptops, tablets, and smartphones.

## Technology Stack
- **HTML5**: Semantic document structure
- **CSS3**: Custom animations, responsive layouts, glassmorphism UI
- **JavaScript**: Dynamic video playback, slider controls, and content navigation

## Live Preview & Setup
Open `index.html` in any modern web browser or deploy directly using GitHub Pages or Vercel.
